# 申请查看你的好感度 · V6 前端演示

## 如何打开
- 联调版：参照上级目录的 DEPLOY_GUIDE.md 启动本机服务。
- 源码版：解压本 ZIP，保持 `index.html`、`app.js`、`styles.css`、`refinement.css`、`wizard.css` 和 `images/` 在原相对位置，双击 `index.html`。

## V6 更新重点
- 顶部独立增加「人物档案」导航入口。
- 登录为前端演示：不会验证手机号、发送短信、调用微信。模拟登录后进入三段式人物档案。
- 第 1 段关于你：昵称、性别、年龄段、MBTI、关系状态、沟通风格和期待。
- 第 2 段关于 TA：仅填写已知信息、沟通风格、观察到的特点及未解疑问。
- 第 3 段关系背景：关系阶段、交流频率、相处事件时间线、边界及分析目标。
- 进度条、步骤点击、上一段/下一段、手机左右滑动、可编辑虚构示例。
- 档案数据只保存在当前运行页面的 JS 内存，刷新后丢失；不会存 localStorage / 服务器。
- 互动报告由本地规则生成。军师对话使用独立后端接入 DeepSeek，未配置时页面会提示。发送时会传输军师对话，只有勾选才附带互动统计和档案选项。
