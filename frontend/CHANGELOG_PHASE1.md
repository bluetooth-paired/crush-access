# V6 第一阶段开发 · 修改记录

## 最小增量原则

基线为已完成 JSON Schema 1.0 修复的 V6。未修改 `styles.css`、`refinement.css`、`wizard.css` 和图片；保留原导航、首页、登录演示、三阶段人物档案、聊天导入、双向画像、圆环/进度条/时间分布以及军师气泡布局。

## 本阶段修改

- `app.js`：增加模式状态、手动切换、两个虚构 Mock 场景按钮、明确的真实发送授权与身份确认、请求中/错误/重试/异步响应失效保护；继续沿用 JSON Schema 1.0 的规范化消息数组；`sender_name` 用于显示、`metadata` 按原结构保留；Dashboard 改为接收动态 UI 数据，军师支持多轮及关联 ID。
- `dashboard.js`：将计算和呈现分离，明确比例/百分数单位转换；仍保留 V6 本地逻辑作为演示。
- `phase1.css`：仅为模式状态、错误提示、按钮和气泡换行添加样式，不重排原页面。
- `api/config.js`、`api/client.js`、`api/adapter.js`：只实现已确认的两个路由和通用传输；业务字段留待 OpenAPI 文档。
- `mocks/`：添加两套纯虚构聊天和 Dashboard，以及静态页可直接引入的数据脚本。
- `index.html`：仅增加静态脚本和 CSS 引用。
- `tests/`：保留并更新 V6 解析回归测试，添加新阶段测试和模拟适配器测试。

## 未完成（需要后端文青）

OpenAPI 的请求/响应字段、业务错误定义、认证、CORS、session 语义、正式分析模型与数值解释、隐私/数据保留说明。当前不能声称真实后端已联通；模拟后端成功测试是前端本地桩。
